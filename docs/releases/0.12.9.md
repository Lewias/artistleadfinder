## Ассистент

- Работает только на Claude Haiku 5.5. Тактика сделки и тон берутся из скиллов продаж, обновлённых по Jarvis.
- Раздела черновиков больше нет. Ассистент отправляет iMessage только по прямой команде «Отправь» или «Ответь». На просьбу предложить текст отвечает в чате.
- Входящие личные iMessage на Mac можно обработать без карточки CRM. «Не связываться» продолжает блокировать отправку.
- Карточки уже переданных сообщений и их статусы остались. Старые неотправленные черновики не ставятся в очередь.
