## Исправления

- Ассистент сразу использует встроенное подключение и не требует настройки.
- Убраны выбор провайдера и моделей, адрес API и поля ключей на всех экранах ассистента.
- В настройках ассистента осталось только подключение Telegram.
- Старые сохранённые настройки больше не меняют встроенное подключение.
- Подтверждения действий и отправки iMessage сохранены.
