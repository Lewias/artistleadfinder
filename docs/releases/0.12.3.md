## Что нового

- Threads: аккаунты через браузерный профиль Instagram, публикации и локальное расписание.
- Работа в трее, настройки фоновой работы и уведомления.
- Готовое подключение OpenCode Go с Haiku 5.5 и общим ключом без его отображения в интерфейсе.
- Ассистент выполняет команды без дополнительного подтверждения; действия iMessage сохраняют подтверждение.
- Ассистент управляет прогревом Instagram, создаёт браузерные профили и меняет прокси.
- Исправлен ввод Direct-сообщений при потере фокуса и задержках редактора; несовпадающий текст не отправляется.
- Поле ввода ассистента располагается у нижнего края окна.

## Установка

Windows: установщик `*_x64-setup.exe`.

Windows Portable: распакуйте `ArtistLeadFinder-Portable.zip` и запустите `artist-lead-finder.exe` внутри папки.

macOS Apple Silicon: откройте `.dmg` и перенесите приложение в «Программы».

Приложение обновит локальную схему базы для Threads. Старая версия может не открыть обновлённую базу.

Общее подключение использует лимит подписки владельца ключа. Ключ в клиентской сборке может быть извлечён из её файлов.
