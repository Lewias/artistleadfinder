## Ассистент

- Правила продаж сохраняются отдельно для каждого аккаунта в папке `sales-rules` на компьютере. Попросите ассистента изменить цену, правило или стиль сообщений прямо в чате.
- По прямой команде ассистент передаёт отдельное iMessage в «Сообщения» на Mac. На Windows сообщение попадает в очередь для Команды на iPhone. Это работает и через подключённый Telegram.

## NSTbrowser

- Исправлено открытие профиля, когда NSTbrowser возвращает пустой список окон в виде `null`. Добавлена поддержка форматов адреса подключения к уже открытому профилю.

## Скачать

- Windows Installer — файл `*_x64-setup.exe`.
- Windows Portable — распакуйте `ArtistLeadFinder-Portable.zip` и запустите `artist-lead-finder.exe`.
- macOS (Apple Silicon) — откройте `.dmg` и перетащите приложение в «Программы».
