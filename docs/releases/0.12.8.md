## Рассылка Instagram

- Рассылка идёт пачками по 5 подтверждённых DM на аккаунт. После каждой пачки приложение примерно 5 минут листает Reels, затем прокручивает ленту и ставит до 3 лайков доступным публикациям. После этого начинает следующую пачку.
- Цикл работает автоматически после запуска рассылки. Пауза и перезапуск сохраняют прогресс. Интервалы между DM и лимиты аккаунта продолжают действовать.
- Недоступные действия пропускаются. Если Instagram требует входа или проверки либо сообщает об ограничении, активность на аккаунте останавливается.

## Скачать

- Windows Installer — файл `*_x64-setup.exe`.
- Windows Portable — распакуйте `ArtistLeadFinder-Portable.zip` и запустите `artist-lead-finder.exe`.
- macOS (Apple Silicon) — откройте `.dmg` и перетащите приложение в «Программы».
