## Профили NSTbrowser и Dolphin Anty

- Во вкладке «Аккаунты» появилась кнопка «NST / Dolphin». Загрузите список и отметьте профили, которые хотите добавить.
- Кнопка «Браузер» открывает подключённый профиль в исходном браузере с его сессией и настройками прокси.
- Профили доступны в общих списках аккаунтов Instagram и Threads.
- Исправлена загрузка списка в версиях NSTbrowser, которые возвращают код 200 в теле успешного ответа.

Для подключения нужен API-ключ выбранного браузера. Откройте настольный клиент на том же компьютере перед запуском профиля. Для запуска через API Dolphin Anty нужен платный тариф.

## Скачать

- Windows Installer: файл `*_x64-setup.exe`.
- Windows Portable: распакуйте `ArtistLeadFinder-Portable.zip` и запустите `artist-lead-finder.exe`.
- macOS (Apple Silicon): откройте `.dmg` и перетащите приложение в «Программы».
