# Этапы сделки и следующее действие

Редактируемый файл. Пороговые дни — стартовые значения, подстрой под свой ритм.
Этап определяется по фактам переписки, а не по ощущению. Если факты противоречат статусу в CRM — указать это и предложить обновление (не менять самому).

| Этап | Вход (что должно быть в переписке) | Следующее действие по умолчанию | Забыт, если |
|---|---|---|---|
| `new` | продюсер написал первым, ответа нет | 1 follow-up с новым поводом | 3+ дня без второго касания |
| `engaged` | артист ответил, идёт разговор | вопрос про цель / релиз | 5+ дней тишины от продюсера после ответа артиста |
| `qualified` | известны цель и таймлайн, есть интерес | сделать один подходящий оффер | 3+ дня без оффера |
| `offer_sent` | названа цена / оффер | ответить на вопросы, мягкий follow-up | 2–3 дня тишины от артиста |
| `negotiating` | возражение, торг, «let me think» | выяснить реальную причину (objection-handling) | 3+ дня без ответа продюсера на возражение |
| `committed` | «I'm in», «send the link», согласовали способ оплаты | дать ссылку / подтвердить оплату | 48 ч без оплаты |
| `won` | оплатил | доставить, через 7–14 дней спросить о результате, потом апсейл | обещанное не доставлено |
| `nurture` | «not now» с причиной или датой | касание к дате / по новому поводу | дата прошла |
| `lost` | ясное «нет» после выяснения причины | ничего; повтор не раньше 90 дней и только с реальным поводом | — |
| `do_not_contact` | opt-out, просьба не писать | ничего | — |

## Приоритет «кому ответить сегодня»
1. Артист написал последним и ждёт ответа (особенно вопрос про цену или оплату) — **отвечать в тот же день**.
2. `committed` без оплаты.
3. Невыполненное обещание продюсера («I'll send the pack tonight» и файла не было).
4. `offer_sent` / `negotiating`, тишина по порогу выше.
5. `nurture`, у которого наступила дата.
6. Остальные тёплые по убыванию оценки.

## Частота касаний (fatigue)
- Не больше **2 follow-up подряд** без ответа, потом пауза минимум **14 дней**.
- После 3–4 касаний без ответа — одно «закрывающее» сообщение (без вины и давления), затем `nurture` или `lost`.
- Возобновление через 60–90 дней — только с **новым поводом**: новый релиз артиста, новый пак под его стиль, реальное изменение цены.
- Короткие сухие ответы, «k», «busy rn» подряд — признак усталости: сократить частоту, не наращивать.
