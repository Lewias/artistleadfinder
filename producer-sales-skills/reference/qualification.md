# Квалификация и оценка намерения купить

Редактируемые критерии. Адаптация BANT / CHAMP под независимого артиста: «бюджет» — это его деньги, «authority» — обычно он сам (иногда менеджер или лейбл), «timeline» — дата релиза.

## Кто хороший лид (ICP)
- Независимый хип-хоп / R&B / смежные жанры артист, который **регулярно выпускает** музыку или готовит релиз.
- Уже вкладывался в музыку (студия, сведение, биты, клипы, промо).
- Сам решает и платит, или дал контакт того, кто решает.
- Есть конкретная цель: релиз, проект, рост аудитории.

## Сигналы (каждый — с цитатой и датой из переписки)

| Группа | Сигнал | Баллы |
|---|---|---|
| Явное намерение | спросил цену, «how much», «what's the price for…» | +20 |
| | сказал «да»: «I'll take it», «I'm in», «let's do it» | +30 |
| | спросил, как платить / «send the link» / «can I pay with…» | +30 |
| | условия лицензии, стемы, эксклюзив, контракт | +15 |
| | попросил конкретный бит или пак «for my next song» | +15 |
| Таймлайн | назвал дату релиза или «dropping soon» в ближайшие 30 дней | +15 |
| | релиз в 1–3 месяца | +8 |
| Деньги | уже платил за биты / промо / студию | +10 |
| | «when I get paid», «next week I'll have it» (деньги есть, но позже) | +5 |
| Вовлечённость | отвечает развёрнуто, задаёт встречные вопросы | +10 |
| | прислал свою музыку / ссылку на трек | +8 |
| | быстро отвечает (обычно < 24 ч) | +5 |
| Fit | активно релизится, есть аудитория, о которой можно говорить | +5 |
| Негатив | «not interested», «I'm good» без объяснения | −25 |
| | спрашивает только бесплатное («free beats?») | −15 |
| | много раз «later» без даты | −10 |
| | 2+ напоминания продюсера подряд без ответа | −15 |
| Стоп | opt-out, просьба не писать, несовершеннолетний | **оценка = 0, стоп** |

Сумма, затем обрезка в диапазон 0–100.

## Шкала

| Баллы | Метка | Что значит |
|---|---|---|
| 75–100 | ready | готов покупать: дать оффер / ссылку на оплату сегодня |
| 50–74 | hot | есть потребность и интерес: квалифицировать до конца и сделать оффер |
| 25–49 | warm | интерес есть, нет таймлайна или денег: прогрев, вопросы |
| 1–24 | cold | слабый интерес: редкие касания с поводом |
| 0 | stop | не писать |

Каждая оценка сопровождается **уверенностью** (high / medium / low). Меньше 3 подтверждённых сигналов → уверенность low, и это говорится прямо.

## Чего не хватает (что выяснять)
Порядок по важности. Один вопрос за сообщение, по ходу разговора, не допросом.
1. **Цель / боль**: что хочет от следующего релиза, что не получается сейчас.
2. **Таймлайн**: когда дроп.
3. **Деньги**: вкладывался ли раньше, сколько готов (косвенно, см. вопросы ниже).
4. **Кто решает**: сам, менеджер, лейбл.

Естественные вопросы (американский английский, без корпоратива и без пунктуации, см. `voice.md`):
- "what are you working on right now"
- "when's the next drop"
- "what'd you do to push your last single"
- "you handling the business side yourself or got a manager"
- "what would make this next one feel like a win for you"

## Дисквалификация (вежливо закрыть или перевести в nurture)
- Нет музыки и планов релиза, только «one day».
- Нужно только бесплатное, после двух предложений платного варианта.
- Явный не-fit (жанр/формат, который продюсер не делает).
- Красные флаги из `guardrails.md`.

Пример закрытия без сжигания мостов:
> all good sounds like the timing's not there yet

> when you're closer to dropping hit me and we'll figure it out
